# طريقة النشر على فيرسل (Vercel)

هذه نسخة المشروع جاهزة للنشر على فيرسل. الصورة الشخصية والسيرة الذاتية موجودة داخل الملفات نفسها — لا حاجة لأي رابط خارجي.

اختر إحدى طريقتين أدناه (الأولى أسهل):

---

## الطريقة الأولى: عبر GitHub (الأسهل والمُستحسنة)

1. فك ضغط هذا الملف على جهازك.
2. حمّل برنامج **Git** من الموقع: https://git-scm.com (إذا لم يكن لديك).
3. أنشئ مستودعاً جديداً على GitHub، ثم ارفع المجلد إليه.
4. ادخل إلى https://vercel.com/new وسجّل دخولك بحساب GitHub.
5. اضغط **Import** واختر المستودع.
6. اترك كل الإعدادات كما هي، ثم اضغط **Deploy**.
7. بعد ثوانٍ قليلة ستحصل على رابط موقعك مثل: `https://your-site.vercel.app`

> يمكن بعدها تحديث الموقع بمجرد رفع أي تعديل جديد إلى GitHub — فيرسل يحدّثه تلقائياً.

---

## الطريقة الثانية: من جهازك مباشرة (سطر الأوامر)

1. فك ضغط هذا الملف وافتح المجلد في الطرفية (Terminal / موجه الأوامر).
2. ثبّت **Node.js** (إصدار 20 أو أحدث) من: https://nodejs.org
3. ثبّت أداة فيرسل ثم انشر:

```bash
npm install
npm i -g vercel
vercel --prod
```

4. عند أول مرة سيطلب تسجيل الدخول ثم أزلة بسيطة — اضغط Enter لكل السؤالات (القيم الافتراضية مناسبة).
5. ستحصل على رابط موقعك في النهاية.

---
