# TreeLink

### حضور مهني واحد، وروابطك المهمة كلها في مكانها.

**TreeLink** صفحة تعريف شخصية للمطوّرة رزان بلاطة، صُممت لتكون نقطة البداية لكل من يريد التعرّف على أعمالها أو التواصل معها. بدل توزيع الحضور المهني بين روابط متفرقة، تجمع الصفحة معرض الأعمال والسيرة الذاتية وملفات العمل الحر في تجربة واحدة واضحة وسهلة التصفح.

الصفحة عربية أولًا، بتصميم داكن هادئ ولمسات لونية مستوحاة من التقنية، وتضع أهم خطوة للزائر في المقدمة: الانتقال إلى معرض الأعمال.

## تجربة الصفحة

تبدأ الصفحة بتعريف موجز برزان وتخصصها كمطوّرة ويب متكاملة، ثم ترتب الروابط بحسب ما يحتاجه الزائر:

1. **استكشاف الأعمال** عبر معرض المشاريع.
2. **التعرّف على الخبرات** من خلال السيرة الذاتية القابلة للتنزيل.
3. **الوصول إلى الملفات المهنية** على مستقل، وخمسات، وUpwork، وبعيد، وفورلانسو، وBright Gaza.
4. **بدء التواصل** بالبريد الإلكتروني أو LinkedIn.

## ما يميز التنفيذ

- واجهة عربية كاملة باتجاه من اليمين إلى اليسار، ومتجاوبة مع الشاشات الصغيرة والكبيرة.
- ترتيب بصري يضع معرض الأعمال في المقدمة، ثم السيرة الذاتية والمنصات المهنية وطرق التواصل.
- حركات دخول خفيفة تحترم إعداد تقليل الحركة في الجهاز.
- روابط خارجية آمنة، وتنزيل مباشر للسيرة الذاتية، وبيانات وصفية لمشاركة الصفحة.
- بيانات الصفحة وروابطها منظمة في مكان واحد لتسهيل تحديثها.

## التشغيل والتطوير

يتطلب المشروع Node.js 20 أو أحدث وnpm.

```bash
npm install
npm run dev
```

أوامر المشروع:

| الأمر             | الوظيفة                     |
| ----------------- | --------------------------- |
| `npm run dev`     | تشغيل خادم التطوير المحلي   |
| `npm run build`   | إنشاء بناء الإنتاج          |
| `npm run preview` | معاينة بناء الإنتاج محليًا  |
| `npm run lint`    | فحص الشيفرة باستخدام ESLint |

## التقنيات المستخدمة

React 19 وTypeScript لبناء الواجهة، وTanStack Start وTanStack Router للتطبيق والتوجيه، وVite للبناء والتطوير. تستخدم الصفحة Tailwind CSS 4 للتنسيقات، وFramer Motion للحركة، وLucide للأيقونات. إعداد Nitro يجهز ناتج البناء للنشر على Vercel.

## تحديث محتوى الصفحة

- **النبذة، بيانات الصفحة، معرض الأعمال، المنصات ووسائل التواصل:** `src/routes/index.tsx`
- **الصورة الشخصية والسيرة الذاتية:** `src/assets/`
- **الألوان، الخطوط، التخطيط والتجاوب:** `src/styles.css`
